retail-inventory-system

Verified
C#.NET 9ASP.NET Core Blazor WASMSQL ServerDocker

A hardware-store class project rebuilt into a real Clean Architecture system: a repository layer that's actually wired to the API instead of sitting unused behind a direct DbContext, BCrypt + JWT replacing a login that compared plaintext passwords in the client, and the domain generalized from a single hardcoded store into a general retail system.

  • Repository layer connected end-to-end — previously registered but never called
  • Centralized exception handling (.NET 8+ IExceptionHandler) replacing 4 duplicated try/catch blocks
  • Domain and Application layers recompiled independently after every change — 0 errors

task-manager-flask

Verified
PythonFlaskSQLAlchemy SQLitePlaywright

A Flask task manager hardened through two rounds of QA. An HTTP test pass caught an IDOR vulnerability that let any signed-in user edit or delete another user's tasks by guessing an ID. A second pass with real Chromium automation caught a username-validation mismatch between server and client that was silently blocking valid signups.

  • IDOR vulnerability found and closed with a per-request ownership check
  • 19 scripted HTTP checks plus a real Playwright/Chromium run against the live app
  • Duplicated validation logic and CSS consolidated into single sources of truth

Verified
PythonPLY (Lex/Yacc)TkinterAST

An interpreter for a custom drawing language: a hand-written lexer and LALR parser built with PLY, an AST-walking evaluator, and a live Tkinter canvas. Four real bugs surfaced only by running the interpreter against real programs — not by reading the grammar.

  • Fixed a missing run() entry point that broke file mode completely

world-of-invenio

Verified
Java 17SwingMavenOOP

A turn-based RPG board game with 10 character classes, reorganized from 14 loose .java files carrying a hidden duplicate-class build error into a proper Maven project. Two QA passes — static review, then headless GUI automation driving real button clicks — found three real bugs that weren't visible from reading the code alone.

  • Fixed a duplicate-class build error masked by an editor setting that ran anyway
